Pack the face as WOFF2, drop the OTF, and correct the font licence

The bundled font is now the WOFF2 build: 6.37 MB down to 1.42 MB, verified lossless
against the OTF it came from — 64,589 glyphs on both sides, 65,824 mapped
characters on both sides, and seven sampled outlines (Latin, CJK, kana, box
drawing, emoji) matching point for point. The OTF has been deleted from the working
tree and is no longer tracked; it can be regenerated from the copy still installed
at %LOCALAPPDATA%\Microsoft\Windows\Fonts, or from the upstream unscii-16-full.woff.

The licence claim is corrected in the same change. The face derives from
unscii-16-full: its own name table records "unsciiCJKV18; unscii-16-full, CJK width
72 units", and all 64,315 mapped characters of that variant are present here. That
variant is the one Viznut's page lists as GPL because of Unifont — it is not public
domain. fonts/COPYING now carries the licence text, and fonts/README.md, README.md
and README.en.md all say so. The skin stays MIT: the font is data the stylesheet
references, not code linked into the plugin.

Also here:
- changed-file counters keep their semantic colours (+N green, -N red); the card
  black-text rule no longer claims them
- diff tints deepened to belong to the same family as their text (#CCFFCC and
  #FFCCCC, instead of the GitHub pastels that read as nothing on grey)
- the diff +/- signs take the marker colour their own row defines
- one global backstop: nothing inside a navy selection may be black, outranking
  every rule that forces black text on cards or inside icon buttons
- package.json lists the font files individually, so the tarball carries the WOFF2,
  fonts/README.md and fonts/COPYING — not the whole directory
